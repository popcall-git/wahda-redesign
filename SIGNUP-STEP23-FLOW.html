#环节设计要点依据
1 验证码页
A		 6 位 OTP 输入框自动前跳、支持整段粘贴;错误态文案沿用 PDF 原稿 "Incorrect verification code entered" 并补充剩余尝试次数;30s 倒计时重发,另提供 WhatsApp 通道备选(部分市场短信不可达);号码行可点 Edit 回退上一步修改 #3 注册与登录市场可达性
2 注册完成态
B		 验证通过先给 "Account created! 🎉" 完成反馈,再抛二选一,避免用户误以为流程还没走完;两卡片权重分明(完善信息=主推绿边、稍后补充=次级灰边),但都不设倒计时/强制——尊重"晚点再填"的选择 #1 新手引导防流失
3 完善信息
C1		 用户名实时可用性检查(命中即标红,衔接 P041 "This username is taken");密码强度条;Full name 分 First/Last 两格;生日用日期选择器(参考 P032 日历组件);性别/国家下拉;字段与 P008 Basic Information 一一对应,提交即写同一份数据 #3 注册与登录#12 身份体系
4 稍后补充
C2		 跳过强制表单,把"完成注册"的成就感直接变现为内容消费;系统先按地区+号码画像生成临时默认资料(如 Region=Indonesia),不阻塞后续任何功能 #1 新手引导注册漏斗优化
5 推荐页
C2		 推荐三要素 Communities / Events / Creators,区块可 See all;信号=地区+号码画像,后续可补兴趣选择(P052 已有兴趣库)做冷启动加权;顶部常驻完成度提示条,点 Settings 直达补全页 #7 内容推荐#8 Feed 消费
6 收口与汇合 两条分支收口到 Discover 固定底栏主界面(你 P002 定稿的全局规范);Settings → Basic Information 是唯一补全入口且永不关闭;推荐页顶部不展示底栏徽章,避免把引导页误认为主界面 #2 全局导航P002 底栏规范
