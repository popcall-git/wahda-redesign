Step-by-Step Conversion MechanismHook / Trigger Timing / Drop-off Recovery

Hooks appear only at emotional peaks; every drop-off has a recovery path that pulls the user back into the funnel.

StepKey InteractionConversion Hook (Timing)Drop-off Recovery
01 Pray Five daily prayer check-ins + streak (12-day flame) + countdown to the next prayer, driving a fixed daily return visit The moment prayer completes, an "After Maghrib · Listen to Surah Al-Mulk" listen hook card appears — the moment of reflection is when the voice moves people most Not listened that night → the same recitation is re-pushed to the top of the Feed the next day; listening 3 days in a row grants a streak bonus
02 Listen Immersive player: recitation + author info on one screen; variable speed / loop; "More from Leslie" for continued browsing After playing ≥60s or completing a passage, the author card's Follow button animates from gray to brand green + a persistent group banner Exit without following → the Feed recommends this author's content the next day (tagged "Recently listening")
03 Follow Profile + Follow (the current design lacks an other-user profile view; added here); following turns on "her new content" notifications by default The follow-success page flows on to show a her group floating card (no modal interruption) Follows but doesn't join → the Feed pushes her posts daily (the intended ops path), group posts tagged "Members discussing"
04 Join group Group page pins the author's group (FROM LESLIE tag + 3 mutual-friend endorsements); Preview before Join The join-success welcome message embeds a members-only offer teaser; a fixed post-Maghrib daily discussion ritual builds return visits Joined but silent → one in-group @ with a mutual-friend topic; after 7 days of inactivity, frequency is reduced rather than removed from the group
05 Purchase Product detail page: author-recommendation endorsement banner + "Why you can trust this" with three trust reasons + Coin escrow (funds released after delivery confirmation) First order members-only price + "Bought 1.2k times by circle members" social proof; Ask Amira to ask the author in one tap Added to cart but unpaid → Coin balance reminder + one limited-time in-group reminder; payment failure routes to the Wallet Top Up quick path

Design principles: ① hooks never interrupt with modals — all embedded as cards (aligned with Top-20 Improvements #6 visual fidelity); ② every drop-off has a Feed/notification recovery path (aligned with the global Notification Center plan); ③ payment uses a unified Coin convention (aligned with the My Hub Wallet entry plan); ④ a guest reaching any hook → Guest Mode registration wall (GUEST-FLOW), and the original path continues after registration.
